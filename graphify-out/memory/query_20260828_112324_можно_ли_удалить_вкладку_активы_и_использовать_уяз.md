# Q: Можно ли удалить вкладку Активы и использовать Уязвимости, Карточки активов и Группы активов?

## Answer

Expanded from graph vocabulary: [asset, assets, card, cards, group, groups, vulnerability, vulnerabilities, navigation, route, router, panel, page, sidebar]. The standalone Assets UI is isolated: AssetsPanel is imported by AssetsPage and tested by assets-panel.test.jsx; AssetsPage is imported by App.jsx. Asset cards and vulnerability views are separate screens with their own data flows. Recommended minimal change: remove Assets from navigation, redirect the legacy /assets route to /asset-cards, keep backend assets APIs and the old component temporarily because other workflows may still depend on their data contracts. The operator workflows remain Vulnerabilities, Asset Cards, and Asset Groups. This avoids maintaining a broken duplicate UI while preserving compatibility.
