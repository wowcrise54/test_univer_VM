# Документация MP VM REST API Client

Этот каталог содержит актуальную документацию проекта, разделённую по аудиториям и задачам.

## Основные документы

- [Системная архитектура](system-architecture.md) — компоненты, границы, API, хранилище, интеграция с MP VM, фоновые задачи и ключевые потоки данных.
- [Руководство оператора](operator-guide.md) — интерфейс, права, сканирование, группы и карточки активов, уязвимости, устранение, автоматизация и обработка ошибок.
- [Разработка и развёртывание](development.md) — требования, локальный запуск, Docker Compose, конфигурация, миграции, тесты, сборка и диагностика.
- [План развития до MVP](mvp-roadmap.md) — приоритеты, новые функции, улучшения надёжности, критерии приёмки и Definition of Done.
- [Краткий обзор архитектуры](ARCHITECTURE.md) — ранее существовавшая компактная схема основных слоёв проекта.

## Правило актуальности

Документация описывает только поведение, подтверждённое текущим кодом и конфигурацией. При изменении API, маршрутов, фоновых процессов, переменных окружения или команд запуска соответствующий документ следует обновлять в той же задаче.
